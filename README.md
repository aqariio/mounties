# Mounties

- Modified controls for horses, using left and right to turn, and forward and backward to accelerate and decelerate. (similar to games like Mount & Blade and Kingdom Come: Deliverance)
- Pressing back and then jump will make the horse rear up
- All horses now have a fixed 20 hearts (40 health)
- Horses can run through water that is one block tall (they will still swim when the water is too deep)
- Horses can now step down one block similar to how they step up one block vertically
- Leaves only collide from the top and slow mobs that travel through them (configurable)
